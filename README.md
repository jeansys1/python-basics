# Python Basics

[Version française](README.fr.md)

Five small Python projects, one for each core concept of the language: **variables, functions, conditionals, loops and exceptions**.

I built them while following Harvard's **CS50P** course (*CS50's Introduction to Programming with Python*). Each project only uses what the course had covered at that point, so the code stays simple and readable.

## Projects

1. **[Variables: Monthly Budget](1-variables)**
   A monthly budget calculator: money left, budget per day, projection over a year and recommended savings.
2. **[Functions: Trip Cost](2-functions)**
   A car trip calculator for carpooling: cost per person, travel time and CO2 emitted.
3. **[Conditionals: Shipping Cost](3-conditionals)**
   A shipping cost calculator, like on an online shop: price by weight and destination, free shipping and express option.
4. **[Loops: Python Quiz](4-loops)**
   A quiz with 10 questions about Python basics, with a score bar and the option to play again.
5. **Exceptions**: coming soon

Each folder has its own README with an example of what the program prints.

## How to run

You only need Python 3 (3.10 or newer for project 3), nothing to install.

```bash
git clone https://github.com/jeansys1/python-basics.git
cd python-basics/1-variables
python3 monthly_budget.py
```

To run another project, go into its folder (`2-functions`, `3-conditionals`, `4-loops`) and run its `.py` file.
